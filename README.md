# Autotranslate

<img src="src/icons/icon.png" alt="Autotranslate 아이콘" width="128" height="128" />

브라우저 탭을 선택해 페이지 안에서 번역하고 원문을 복원하는 Manifest V3 TypeScript 확장. 번역은 **온디바이스 PLaMo 3**로 실행.

## 0.1.12

- ONNX 전용: 기존 q4f16 WebGPU 커널·연속 배칭과 ONNX Runtime 대체 경로 유지. GGUF 가져오기·추론·패키징 제거.
- 전체 페이지 번역, 최대 8개 동시 번역, 즉시 표시(애니메이션 없음) 설정 제공.
- 이전 GGUF 저장 데이터는 자동 삭제하지 않음. ONNX 모델을 설치·선택해야 번역 가능.
- GitHub Release는 Chrome ZIP과 SHA-256 체크섬만 제공. Firefox는 실제 ONNX 추론이 미검증인 실험용 빌드.

## 사용법

### 설치
```sh
npm install
npm run build   # build/chrome, build/firefox, dist/*.zip 생성
```
Chrome: `chrome://extensions` → 개발자 모드 → 압축해제된 확장 프로그램 로드 → `build/chrome`
Firefox: `about:debugging` → 임시 추가 기능 로드 → `build/firefox/manifest.json`

Node 24+, WebGPU with `shader-f16` 필요. Chrome 최소 버전은 121. Firefox 빌드는 실험용이며 실제 ONNX 추론은 미검증.

### 첫 실행
설치 후 온보딩이 열림.

1. 번역 대상 언어 선택
2. 모델 설치: 다운로드 또는 로컬 파일 선택 → OPFS에 저장
3. 설정 완료 클릭

모델은 최초 1회만 다운로드. 기본은 `TeamFlaxia/plamo-3-translate-0.8b-onnx` q4f16, 약 705 MB. 토크나이저와 config 함께 저장.

확장프로그램은 **ONNX 형식만 지원**. 로컬 가져오기는 `.onnx` 그래프와 토크나이저·설정 파일을 함께 선택. 이전에 저장한 GGUF 파일은 자동 삭제하지 않지만 실행할 수 없으며, 모델 관리에서 직접 삭제할 수 있음.

### 번역 켜기/끄기
팝업의 스위치로 탭 단위 제어.
- ON: 해당 탭만 번역, 새 DOM도 추적
- OFF: 원문 복원, 대기 요청 취소. 직접 끈 선택은 탭을 닫을 때까지 URL·언어 자동 번역 규칙보다 우선함.

### 설정
설정에서 다음 항목을 관리함.
- **모델 관리**: 기본 모델 다운로드, 디스크에서 ONNX 그래프와 토크나이저·설정 파일 가져오기, 설치된 모델 선택·불러오기, 삭제. 모델이 로컬에 있으면 네트워크 없이 동작.
- **번역 언어**: 제공되는 전체 언어 목록에서 대상 언어 선택. 원문 언어는 자동 감지.
- **항상 번역할 URL**: `example.com/news/*`는 한 경로 구간, `example.com/news/**`는 더 깊은 경로도 일치. 호스트에서도 `*`는 한 구간, `**`는 여러 구간에 대응하며 `http://`·`https://`는 생략 가능. 추가·삭제 즉시 저장. 기존 `never` 규칙은 목록에 표시되며 삭제하기 전까지 차단을 유지.
- **항상 번역할 원문 언어**: 체크 목록에서 복수 선택 후 저장. 대상 언어와 같은 언어는 체크해도 번역하지 않음.
- **동시 번역**: 1/2/4/8개 선택, 새 설정은 기본 8개. 저장된 1/2개 선택은 유지. 탭별 FIFO와 탭 간 순환 배분으로 확장 전체의 생성 슬롯을 공유하며, 처리량이 늘어도 개별 요청의 첫 결과는 늦어질 수 있음.
- **번역 표시**: 기본 오로라 효과 또는 **즉시 표시(애니메이션 없음)** 선택 후 저장. 즉시 표시는 스트리밍 결과와 완료 텍스트의 표시 대기·페이드를 제거하며, 진행 중인 번역에도 적용. 모델 계산 속도와 조각의 읽기 순서는 바꾸지 않음.

URL 패턴 **또는** 감지된 원문 언어가 일치하면 활성 탭만 자동 번역하여 읽지 않는 탭의 모델 작업이 쌓이지 않음. 목록이 비어 있으면 팝업에서 직접 켠 탭만 번역. 설정 상단의 현재 탭 스위치는 환경설정과 별개로 해당 탭만 제어. 탭을 닫으면 선택이 사라지고, 세션 저장으로 서비스 워커 정지 시 유지.

## 기술 요약

### 확장 UI
- 팝업·설정·시작 화면은 slate 중립색과 yellow 강조색을 공유하며 시스템의 밝은/어두운 테마를 따름.
- `src/styles.css`: 색상 토큰, 타이포그래피, 네이티브 버튼·입력·스위치 스타일의 단일 정의. 스위치 thumb는 켜짐·꺼짐 및 밝은·어두운 테마에서 흰색 유지(고대비 모드는 시스템 표시 사용).
- `src/lib/components.ts`: Shadow DOM 기반 `<at-shell>`(화면 폭·여백), `<at-panel>`(패널 모양·간격). 컨트롤은 light DOM에 두어 기존 이벤트, 다국어 처리와 label 연결을 유지.
- 좁은 사이드 패널에서는 단일 열로 표시. 키보드 포커스, 고대비 모드, 동작 줄이기 설정 지원. React/Tailwind 런타임 의존성 없음.
- 아이콘 원본은 `src/icons/icon.png`. 교체 후 `npm run icons`로 투명도·비율을 보존한 16·32·48·128px PNG를 생성. 이미지 처리는 개발용 `sharp`로만 수행하며 확장 런타임에는 포함하지 않음.

### 모델
- 기본: PFN PLaMo 3 Translate 0.8B ONNX q4f16. 자체 WebGPU 커널 우선, ONNX Runtime 대체 경로 지원. 토크나이저는 Transformers.js 사용.
- 무압축 ONNX fp16 버전은 ONNX Runtime 경로로 지원. 속도 최적화 기준은 기존 q4f16 파일이며 모델 재양자화나 그래프 변경은 하지 않음.
- 언어: 카드 기준 53개. 설정에서는 기존 언어 카탈로그 전체를 제공
- 프롬프트는 모델의 `chat_template.jinja`를 사용. `dataset → context → input → output` 순서. 페이지 정보는 한 줄 컨텍스트로만 전달.

페이지 텍스트는 브라우저를 벗어나지 않음.

### 번역 대상 결정
- 탭 단위 스위치 또는 URL·원문 언어 규칙으로 활성 탭을 선택. 콘텐츠 스크립트는 `at/content-translate` 메시지로 주입 후 실행.
- DOM 수집: 텍스트 노드 워커 → run 병합. `<code>`, `pre`, contenteditable 등은 무시.
- Unicode 글자가 없는 숫자·기호 문자열, 명확한 URL·이메일·핸들/ID, 작성자·프로필 등 의미가 확인된 이름 표시는 제외. 일반 문장에 등장하는 이름이나 짧은 본문 단어는 유지.
- 페이지 컨텍스트 수집: Open Graph, JSON-LD, microdata, 랜드마크, lang 속성 → 종류, 사이트, 섹션, 엔티티 추출.
- 순위: **화면에 보이는 본문 → 보이는 보조 UI**. 화면 안 작업이 끝나고 화면이 500ms 안정되면 아래쪽 화면 밖 본문을 미리 번역. DOM 작업 구간은 최대 480자이며, 모델에 보낼 때 실제 토크나이저 기준 최대 64 원문 토큰으로 분할. 숨겨진 탭에서는 유휴 미리 번역하지 않으며 탐색은 `maxNodes` 한도 내에서 수행.
- 의미적 영역과 실제 배치를 함께 사용. 충분한 크기의 grid/flex 다단 및 CSS 다단 문서는 열을 따라 읽으며 RTL 방향도 반영. 불확실한 구조는 화면 위치순.
- 직접 포커스·선택·펼친 영역을 우선하며, 진행 중 읽기 단위는 최대 32개 작업 구간까지 이어서 처리하여 댓글 사이 왕복을 줄임. 스크롤·직접 선택은 이 연속 처리보다 우선하고, 매우 긴 단위는 다른 본문에 양보.
- 스크롤/리사이즈 시 같은 정책으로 재정렬. MutationObserver로 동적 삽입 추적하되, 단순 갱신에는 우선권을 주지 않음.

### 최적화
- **전체 페이지 처리**: 보이는 콘텐츠를 먼저 시작한 뒤 화면 밖의 모든 번역 가능한 원문도 스크롤 없이 처리. 숨김·편집·보호 영역과 잘린 비공개 접미부는 번역하지 않음.
- **진행형 결과**: 호스트의 토큰 기준 분할과 스트리밍 사용. 한 읽기 단위의 여러 조각도 선택한 슬롯 안에서 동시 생성하되, 앞 조각이 완료되기 전에는 뒤 조각을 표시하지 않음. 독립된 단위는 먼저 완료된 것부터 표시. 실패·취소는 형제 작업까지 중단.
- **메모리 안전 쓰기**: `Text.nodeValue`만 변경. 원본은 Map에 보관, 정확 복원 가능.
- **배치 디코딩**: 하나의 모델 worker에서 네이티브 커널의 최대 8개 독립 요청 슬롯을 연속 배칭. ORT worker 폴백은 `C.ENGINE_BATCH` 크기의 고정 cohort를 사용. 페이지 동시 처리 폭과 엔진 슬롯 수는 별개.
- **커널**: ONNX MatMulNBits Q4용 WGSL GEMV/GEMM, RMSNorm, RoPE, Attention, SwiGLU. 기존 q4f16 연산과 연속 배칭을 유지. 과거 형식 비교를 포함한 측정 조건과 결과는 [성능 기록](docs/translation-performance.md) 참조.
- **프롬프트 비용 절감**: 컨텍스트 최대 240자, 페이지 라인 + 영역 라인은 선택적. 글러스는 일관성용 수집만.
- **결과 재사용**: 성공한 번역과 조각을 같은 세션의 모델·언어·문맥 범위에서 재사용. 실패·취소 출력은 저장하지 않으며 모델/언어 변경 시 이전 캐시를 혼용하지 않음.
- **문장 분할·배치**: 호스트의 실제 토큰 수로 64토큰 이하 조각을 구성하며 긴 문장은 단어·자소 경계로 나눔. 문자 수 기준의 중복 분할·직렬 대기를 제거. 자체 WebGPU 엔진은 여러 원문을 독립 시퀀스로 처리하며 최대 8행에서 가중치를 공유하고 결과 인덱스를 유지. 직렬 런타임 대체 경로만 번호 매긴 프롬프트 사용.
- **공유 세션**: 탭 간 요청은 동일 세션 공유, 중복 로드 없음. 모델 로드 후 10분 유휴 시 해제.

번역 실패·취소 시 진행 효과를 정리하고, OFF에서는 원문을 복원. 부분 번역이 대기하면 짧은 연결 유예 후 오로라 색을 없애고, 재개 시 같은 애니메이션을 이어감. Reduced motion/forced colors 시 애니메이션 비활성화.

Notion 단어집 연동과 별도 의사결정 모델은 [연구 및 설계안](docs/translation-performance.md#site-independent-selection-and-decision-model-assessment)에 정리. 단어집 커넥터·가져오기 UI는 아직 구현된 기능이 아님.

개인정보: 번역은 기기 내에서 실행. 모델 다운로드 외에는 번역을 위한 네트워크 요청이 없음. 이전 버전에 저장된 서버 설정과 인증정보는 설정을 불러올 때 제거.
